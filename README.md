# 👕 ReWear – Second-Hand Clothing Marketplace

Second-Hand Clothing Marketplace | Academic Project

---

## 📌 Project Overview

ReWear is a web-based second-hand clothing marketplace developed as an academic project. The system aims to provide a convenient platform for buying and selling second-hand clothing while promoting sustainable fashion and reducing clothing waste.

---

## 🎯 Objectives

- Develop an online marketplace for second-hand clothing.
- Promote sustainable fashion and reduce textile waste.
- Design a user-friendly and efficient information system.
- Apply system analysis and database design concepts.

---

## ✨ Key Features

- User Registration & Login
- Product Management
- Product Search
- Shopping Cart
- Order Management
- Payment Confirmation
- User Profile
- Admin Dashboard

---
